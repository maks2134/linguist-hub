# Deploy: Neon + Render + Vercel

```
Browser → Vercel (Next.js) → Render (Go Fiber Docker) → Neon (Postgres)
                          ↘ OpenRouter LLM API (from Render only)
```

Blueprint: [`render.yaml`](./render.yaml) (free web service, Docker, `backend/`).

## 1. Neon

1. Project `linguist-hub` (`dry-union-33518524`).
2. `DATABASE_URL` with `sslmode=require`.

## 2. Render (backend)

1. https://dashboard.render.com → **New** → **Blueprint**
2. Connect GitHub repo `maks2134/linguist-hub`
3. Apply `render.yaml`
4. Set secret env (Dashboard → Environment):

| Key | Value |
|-----|--------|
| `DATABASE_URL` | Neon connection string |
| `LLM_API_KEY` | OpenRouter key |
| `ALLOWED_ORIGINS` | `https://your-app.vercel.app` |

`JWT_SECRET` is auto-generated by the blueprint.

Healthcheck: `GET /healthz`  
URL shape: `https://linguist-hub-api.onrender.com` (confirm in dashboard)

> Free tier spins down after idle (~cold start). Fine for portfolio demos.

## 3. Vercel (frontend)

- Root Directory: `frontend`
- Build-time env:

| Key | Value |
|-----|--------|
| `NEXT_PUBLIC_API_URL` | `https://linguist-hub-api.onrender.com` |
| `NEXT_PUBLIC_WS_URL` | `wss://linguist-hub-api.onrender.com` |

## 4. Smoke test

1. Open Vercel URL → register / login  
2. Hub → diagnostic chat  
3. Voice/tutor WS (if used)  
4. Confirm CORS (no browser console block)  

## Auth note

JWT is stored in **localStorage** and sent as `Authorization: Bearer`.  
WebSocket uses `Sec-WebSocket-Protocol: bearer,<jwt>` (query `?token=` still accepted as fallback).
